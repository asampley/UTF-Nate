Web Interface of {{ bot_name }}

This interface lets you run bot commands from your browser. This lets you:

  • Run commands without opening discord (like help)
  • Run commands without building up a chat history (like roll)
  • Create a link that could run a command for you when clicked (like clip bnw/angels)
  • Create an html page with many links or buttons to run commands when clicked (custom soundboard anyone?)
  • Create a script to automatically run commands in response to anything you can dream (like play a sound whenever the Oilers score)

To get started, use the `token` command in a server. Follow the link it responds with. This allows the bot to know who's asking (for commands like `intro` that target yourself), and for what server (for commands like `botintro` or `volume` that need to know).

For now the interface doesn't support multiple servers well.
